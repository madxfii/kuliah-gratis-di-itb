    Capaian Pembelajaran Mata Kuliah (CPMK)
    1. CPMK1. Menjelaskan perbedaan jenis pembelajaran unsupervised dan supervised
    2. CPMK2. Menjelaskan dan mengimplementasikan algoritma sederhana untuk kedua jenis pembelajaran tersebut
    3. CPMK3. Menyajikan hasil pilihan jenis pembelajaran yang tepat untuk kasus persoalan/ aplikasi tertentu
    4. CPMK4. Melakukan evaluasi terhadap kinerja suatu algoritma pembelajaran pada kasus persoalan tertentu
    1. Explain the differences between unsupervised and supervised learning types
    2. Explain and implement simple algorithms for both types of learning.
    3. Presenting the results of selecting the appropriate type of learning for a particular problem/application case.
    4. Conducting an evaluation of the performance of a learning algorithm in a particular problem case.
