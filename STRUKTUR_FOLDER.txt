CARA MENGGUNAKAN
================================================================================

1. MENAMBAH BAHAN KAJIAN
   □ Buka folder: kurikulum-itb/[KODE]-[nama]/bahan-kajian/
   □ Buat file: 01-topik-1.md, 02-topik-2.md, dst
   □ Ikuti template markdown yang tersedia

2. MENAMBAH CAPAIAN PEMBELAJARAN (CPMK)
   □ Buka folder: kurikulum-itb/[KODE]-[nama]/capaian-pembelajaran/
   □ Buat file: cpmk-1-deskripsi.md, cpmk-2-deskripsi.md, dst
   □ Hubungkan dengan bahan kajian menggunakan link relatif

3. MEMELIHARA STRUKTUR
   □ Gunakan markdown untuk semua file teks
   □ Jaga urutan file dengan numbering (01-, 02-, etc)
   □ Sertakan metadata di bagian atas file
   □ Buat link internal menggunakan path relatif
