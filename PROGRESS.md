## 🔗 How to Contribute

### Want to help?
1. **Pick a mata kuliah** from "To Do" list above
2. **Comment below** atau buat GitHub Issue to claim it
3. **Use `/kurikulum-builder`** skill untuk generate materi
4. **Submit PR** dengan hasil

### Contoh:
```bash
/kurikulum-builder 2 IF1210 "Algoritma dan Pemrograman 1" \
  "Konsep dasar algoritma|Analisis kompleksitas|Sorting & Searching|Implementasi" \
  "Memahami algoritma fundamental|Menganalisis dan implementasi algoritma"
```

### Assignment Format:
```
- [ ] **[KODE]** - [Nama MK]
  - Assigned to: @[username]
  - PR: [link ke PR]
  - Status: In Progress / Review / Done
```
