# CPMK 2: Mahasiswa dapat memaknai dan menganalisis data untuk perencanaan, forecasting, dan pengambilan keputusan

**Mata Kuliah:** IF2240
**Capaian Pembelajaran ke:** 2

## Pernyataan Capaian
Mahasiswa dapat memaknai dan menganalisis data untuk perencanaan, forecasting, dan pengambilan keputusan

## Indikator Pencapaian
- [ ] Mahasiswa dapat memahami konsep utama
- [ ] Mahasiswa dapat menerapkan dalam praktik
- [ ] Mahasiswa dapat menganalisis masalah terkait
- [ ] Mahasiswa dapat mengevaluasi solusi

## Sub-Topik Terkait
- Referensi ke bahan kajian
- Materi pendukung

## Metode Penilaian
- Ujian/Kuis: 40%
- Tugas/Praktikum: 40%
- Partisipasi: 20%
