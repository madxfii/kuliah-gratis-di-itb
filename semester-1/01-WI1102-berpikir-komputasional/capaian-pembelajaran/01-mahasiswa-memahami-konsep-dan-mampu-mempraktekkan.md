# CPMK 1: Mahasiswa memahami konsep dan mampu mempraktekkan proses berpikir komputasional yang tepat dan terarah untuk pemecahan masalah.

**Mata Kuliah:** WI1102
**Capaian Pembelajaran ke:** 1

## Pernyataan Capaian
Mahasiswa memahami konsep dan mampu mempraktekkan proses berpikir komputasional yang tepat dan terarah untuk pemecahan masalah.

## Indikator Pencapaian

### Level 1: Pemahaman (C1-C2)
- [ ] Dapat menjelaskan definisi Computational Thinking menurut Jeannette Wing dan ISTE/CSTA framework
- [ ] Dapat membedakan antara Computational Thinking, Computer Science, dan Programming
- [ ] Dapat menjelaskan mengapa Computational Thinking penting di era digital (21st century skills)

### Level 2: Identifikasi (C2)
- [ ] Dapat mengidentifikasi dan menjelaskan **empat pilar CT**: Dekomposisi, Pengenalan Pola, Abstraksi, Desain Algoritma
- [ ] Dapat memberikan minimal **3 contoh konkret** untuk setiap pilar dari kehidupan sehari-hari, domain bisnis, atau IT
- [ ] Dapat mengenali pilar-pilar mana yang digunakan dalam berbagai skenario masalah

### Level 3: Aplikasi (C3)
- [ ] Dapat menerapkan proses Computational Thinking untuk memecahkan masalah sederhana yang belum pernah dilihat sebelumnya
- [ ] Dapat **mendekomposisi masalah kompleks** menjadi sub-problems yang manageable
- [ ] Dapat mengidentifikasi dan mengabstraksi informasi penting dari masalah yang kompleks
- [ ] Dapat merancang **step-by-step solution** (pseudocode atau algoritma) untuk masalah sederhana

### Level 4: Implementasi (C3)
- [ ] Dapat mengimplementasikan solusi Computational Thinking dalam **pseudocode** yang jelas
- [ ] Dapat mengimplementasikan solusi dalam **visual programming (Snap!)** dengan proper structure (sequence, loop, conditional, variables, functions)
- [ ] Dapat mengimplementasikan solusi dalam **text-based programming (Python)** dengan code yang readable dan well-commented
- [ ] Dapat mentransfer pemahaman dan kode **antar tools** (dari Snap! ke Python atau sebaliknya dengan understanding yang sama)

## Sub-Topik Terkait
- **Modul 1**: Konsep Dasar Computational Thinking
  - Sub 1.1: Definisi & Konteks CT
  - Sub 1.2: Empat Pilar CT (Dekomposisi, Pengenalan Pola, Abstraksi, Algoritma)
  - Sub 1.3: CT dalam Praktik (studi kasus real-world)
  
- **Modul 2**: Transformasi Solusi CT ke Kakas Komputasional
  - Sub 2.1: CT vs Programming (konsep yang sama, tools berbeda)
  - Sub 2.2: Block-Based Programming (Snap!) — implementasi CT dengan visual blocks
  - Sub 2.3: Algoritma dalam Snap! (search, sort, logic)
  - Sub 2.4-2.6: Python basics, algorithms, debugging (transfer ke text-based)

## Metode Penilaian
- Ujian/Kuis: 40%
- Tugas/Praktikum: 40%
- Partisipasi: 20%

## Contoh Luaran Pembelajaran

### Bentuk Evidence:
1. **Quiz & Kuis Formatif** (Modul 1)
   - Jelaskan definisi CT & pilar-pilarnya dengan kata-kata sendiri
   - Identifikasi pilar mana yang digunakan dalam skenario yang diberikan

2. **Case Study Analysis** (Modul 1.3)
   - Analisis studi kasus real-world (Google Maps, data science, healthcare)
   - Identifikasi dekomposisi, pattern recognition, abstraction, algorithm yang digunakan
   - Tulis pseudocode untuk satu masalah sederhana

3. **Mini-Project 1: Snap! Game/Story** (Modul 2.2)
   - Develop interactive game atau story dengan Snap!
   - Demonstrate: sequence, loop, conditional, variables, functions
   - Proof bahwa student memahami logic di balik blocks (bukan hanya copy-paste)
   - Code review reflection: "Dekomposisi apa yang saya gunakan?"

4. **Mini-Project 2: Python Problem-Solving** (Modul 2.4-2.5)
   - Solve 2-3 computational problems dalam Python
   - Demonstrate algorithms learned (search, sort, atau custom algorithm)
   - Code quality: readable, commented, handles edge cases
   - Test cases written & verified

### Kriteria Pencapaian:
- **Kompeten**: Mahasiswa bisa explain CT concepts, apply ke masalah sederhana, implement dalam 1 tool (Snap! ATAU Python)
- **Sangat Kompeten**: PLUS implement dalam 2 tools, transfer knowledge antar tools, analyze efficiency tradeoffs
- **Excellent**: PLUS apply ke novel problems, think about edge cases & optimization, mentor peers
