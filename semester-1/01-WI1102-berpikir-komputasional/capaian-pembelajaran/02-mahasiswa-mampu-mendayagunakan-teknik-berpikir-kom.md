# CPMK 2: Mahasiswa mampu mendayagunakan teknik berpikir komputasional untuk menganalisis permasalahan baru, dan menghasilkan solusi atas permasalahan tersebut.

**Mata Kuliah:** WI1102
**Capaian Pembelajaran ke:** 2

## Pernyataan Capaian
Mahasiswa mampu mendayagunakan teknik berpikir komputasional untuk menganalisis permasalahan baru, dan menghasilkan solusi atas permasalahan tersebut.

## Indikator Pencapaian

### Level 1: Analisis (C4)
- [ ] Dapat menganalisis problem baru (tidak pernah dilihat sebelumnya) dan mengidentifikasi CT techniques yang paling sesuai
- [ ] Dapat break down problem kompleks menjadi sub-problems yang manageable
- [ ] Dapat identify patterns dalam problem yang dapat dimanfaatkan untuk solve lebih efisien
- [ ] Dapat recognize data structures dan algorithms yang relevan untuk problem

### Level 2: Desain Solusi (C4)
- [ ] Dapat merancang solusi komputasional yang efektif dengan mempertimbangkan:
  - Correctness (apakah solve problem dengan benar?)
  - Efficiency (apakah reasonably fast untuk data size expected?)
  - Clarity (apakah other programmers bisa understand?)
  - Trade-offs (lebih cepat vs lebih readable, space vs time)
- [ ] Dapat membuat pseudocode atau flowchart yang clear & detailed
- [ ] Dapat memilih data structures yang appropriate (list, dictionary, dll)
- [ ] Dapat select atau design algorithms yang suitable untuk problem constraints

### Level 3: Implementasi & Testing (C3)
- [ ] Dapat mengimplementasikan solusi dalam bahasa pemrograman (Snap! atau Python) dengan code yang:
  - Correct: produces expected output untuk test cases
  - Readable: meaningful variable names, proper indentation, comments
  - Robust: handles edge cases (empty input, boundary values, large inputs)
- [ ] Dapat write test cases untuk verify correctness
- [ ] Dapat debug program yang tidak bekerja dengan systematic approach
- [ ] Dapat optimize code untuk efficiency (time atau space) jika diperlukan

### Level 4: Evaluasi & Komparasi (C5)
- [ ] Dapat membandingkan multiple solutions untuk same problem dan evaluate trade-offs
- [ ] Dapat analyze time & space complexity dari algorithms (Big O notation understanding)
- [ ] Dapat explain kapan algorithm A lebih baik dari algorithm B
- [ ] Dapat melakukan code review pada kode orang lain & memberikan constructive feedback

### Level 5: Transfer & Kreativitas (C6)
- [ ] Dapat mentransfer CT skills ke masalah baru & domain yang belum pernah encountered sebelumnya
- [ ] Dapat design original solutions yang creative & innovative
- [ ] Dapat apply CT principles untuk solve real-world problems dalam specific domains (data science, cybersecurity, healthcare, dll)
- [ ] Dapat berpikir kritis tentang ethical & societal implications dari solusi yang didesain

## Sub-Topik Terkait
- **Modul 2**: Transformasi Solusi CT ke Kakas Komputasional (praktik menganalisis & solve problems)
  - Sub 2.2-2.3: Block-based programming (Snap!) — Mini-Project 1
  - Sub 2.4-2.6: Text-based programming (Python) — Mini-Project 2 & debugging
  
- **Modul 3**: Dampak & Tren Komputing pada Domain Tertentu (analyze problems dalam different domains)
  - Sub 3.1: Aplikasi CT dalam domain spesifik (data science, cybersecurity, AI/ML, healthcare, dll)
  - Sub 3.2: Tren teknologi & implikasi masa depan
  - Sub 3.3: Dampak sosial & ethical evaluation — Mini-Project 3

## Metode Penilaian
- Ujian/Kuis: 40%
- Tugas/Praktikum: 40%
- Partisipasi: 20%

## Contoh Luaran Pembelajaran

### Bentuk Evidence:

1. **Mini-Project 2: Python Problem-Solving** (Modul 2.4-2.6)
   - Solve computational problems (search, sort, data processing)
   - Demonstrate problem analysis & algorithm selection
   - Code dengan proper testing & edge case handling
   - Document thinking process (why this algorithm? trade-offs?)

2. **Algorithm Comparison Analysis** (Modul 2.3, 2.5)
   - Linear vs Binary search — ketika gunakan masing-masing?
   - Bubble vs Selection sort — efficiency comparison
   - Time complexity analysis (Big O notation)
   - Written explanation tentang trade-offs

3. **Code Review & Refactoring** (Modul 2.6)
   - Review kode (milik sendiri atau peer)
   - Identify improvements: readability, efficiency, correctness
   - Refactor code untuk better quality
   - Reflect on learning

4. **Mini-Project 3: Domain Exploration & Ethical Analysis** (Modul 3)
   - Choose domain (data science, cybersecurity, AI/ML, healthcare, sustainability, games)
   - Research: how is CT applied dalam domain?
   - Analyze: what are positive & negative impacts?
   - Propose: ethical solution yang balance efficiency, fairness, accessibility
   - Evaluate: who is responsible? What are consequences?

### Kriteria Pencapaian:
- **Kompeten**: Bisa analyze problems independently, design reasonable solutions, implement dengan correct results
- **Sangat Kompeten**: PLUS evaluate multiple solutions, compare efficiency, think about edge cases & optimization
- **Excellent**: PLUS transfer skills ke novel problems, design creative solutions, consider ethical implications & broader impact, mentor peers
