## Pedagogical Approach untuk Modul 2

### Scaffolding Strategy
- **Start visual (Snap!)** → lower cognitive load, can focus on logic
- **Then transition to text (Python)** → introduces syntax complexity gradually
- **Side-by-side comparisons** → helps transfer knowledge between tools
- **Hands-on projects** → "learning by doing" approach

### Formative Assessment
- Guided activities dengan check-your-understanding
- Peer code reviews → learn different approaches
- Mini-projects dengan clear rubrics
- Reflections → metacognitive thinking

### Support Mechanisms
- Error messages interpreted & explained
- Common mistakes addressed
- Debugging strategies taught explicitly
- Optional deep-dives untuk interested students

## Expectations & Mindset

### Programming adalah Learning Journey, Bukan Sprint
- **Expect frustration** — bugs, errors, tidak bisa understand code. **This is NORMAL!**
- **Celebrate small wins** — first program runs, first bug fixed, first algorithm implemented
- **Growth mindset** — "I can't do this YET" bukan "I can't do this"

### Mistakes & Bugs are Learning Opportunities
- **Every programmer encounters bugs** — even experts
- **Debugging is a skill** — learn to diagnose problems systematically
- **Errors teach you** — misunderstanding error message → now you know

### Coding is Like Writing
- **Syntax** (grammar) must be correct, but **logic** (content) matters more
- **Rewriting** (refactoring) is normal and healthy
- **Plagiarism** is bad, but **learning from others' code** is good (with attribution)
